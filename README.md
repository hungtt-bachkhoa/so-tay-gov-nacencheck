# Sổ tay Gov Portal

Website tài liệu độc lập dùng VitePress, giới thiệu phân hệ Gov Portal của NacenCheck theo ngôn ngữ dành cho người mới.

## Chạy trên máy

Yêu cầu Node.js 18 trở lên.

```bash
npm install
npm run dev
```

Mặc định VitePress in địa chỉ truy cập ra terminal, thường là `http://localhost:5173`.

## Build bản tĩnh

```bash
npm run build
npm run preview
```

Thư mục kết quả là `docs/.vitepress/dist`.
